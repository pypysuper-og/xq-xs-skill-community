# v0.1.0｜用繁體中文，把交易想法寫成 XS

XQ × XS Community 首個社群發行版，面向台灣投資與交易者，協助支援 `SKILL.md` 的 AI agent 撰寫、解釋、除錯與審查 XQ 的 XS／XScript。

## 主要內容

- 五類 XS 工作：指標、警示／策略雷達、選股、自動交易與自訂函數。
- 九份主題參考：語法、類型、資料／時間、函數／狀態、選股／警示、交易、審查、來源與範例。
- 1,455 筆名稱及來源索引，含 22 篇語法運用文章；資料、報價與選股同名欄位分開保留。
- 1,419 支官方範例的固定版本路徑與 blob SHA 索引。
- 六個原創 XS 範例；交易範例預設關閉交易指令。
- Python 3.10+ 離線查找與可攜 ZIP，不需第三方 Python 套件。
- 面向繁體中文讀者的操作介紹、提問範例與 AI 生成封面。

## 下載與使用

下載本 release 的 `xq-xs-community-v0.1.0.zip`，核對旁附的 `.sha256`，解壓後將完整 `xq-xs/` 放進 agent 支援的 skills 目錄。以 `$xq-xs` 明確叫用。安裝與範例見 [README](https://github.com/pypysuper-og/xq-xs-skill-community/blob/v0.1.0/README.md)。

本 release 的 ZIP 只包含可安裝 skill、參考文件、識別索引、查找工具、原創範例與授權；上游手冊全文與官方程式本體保留在原出處。
