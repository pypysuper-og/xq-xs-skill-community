# v0.3.0：官方 Skill 參考與 SDT／Group 查找

舊離線索引未涵蓋部分 SDT 與 Group 名稱，容易讓寫作時的查找停在過時資料。本版下載 XQ [〈用 ChatGPT 寫 XS 腳本〉](https://www.xq.com.tw/xstrader/%E7%94%A8chatgpt%E5%AF%ABxs%E8%85%B3%E6%9C%AC/) 所附 Skill，選出值得整合的主題，再用官方個別頁面、SDT 清單與固定版本程式確認代表性的技術細節。

## 新增內容

- 14 份主題參考，新增 SDT／Group 與來源包審查，補充共享作用範圍、條件更新及商品清單。
- `lookup.py --source supplement` 提供 50 筆識別 metadata：38 個 SDT 名稱與 12 項函數／宣告。`all` 可合併四個來源，預設仍為 `help`。
- 補充 `SetAlign`、欄位支援與缺值、更新日期、`StandardDev`、`Extremes`、Rank 排除極端值及 `xfMin_EMA` 文件差異。
- 文章索引由 11 篇增為 12 篇；保留指定分類頁與額外指定文章的範圍差別。
- 記錄下載檔案及 18 個成員的 SHA-256；可辨認連結日後是否換檔。

補充索引的 `checked_on` 與 `evidence` 分別保留日期與證據層級。`catalog-entry` 只代表清單可見，`help-page` 表示讀過個別說明；這些都不是最低版本、資料權限或編譯成功的保證。

來源包未見授權檔，本版只發布重新撰寫的摘要與來源識別資訊，沒有收錄其手冊、上游範例、圖示或 Python checker，也沒有執行該包程式。

## 使用方式

下載本頁的 `xq-xs-community-v0.3.0.zip` 與 `.sha256`，保留完整 `xq-xs/` 資料夾。從解壓後的目錄執行：

```powershell
uv sync --locked --project xq-xs
uv run --locked --project xq-xs python xq-xs/scripts/lookup.py SDT_GetValue --source supplement --json
uv run --locked --project xq-xs python xq-xs/scripts/lookup.py ChatGPT --source articles --json
```

Python 仍固定 3.13.5，零第三方 Python 依賴。桌面編譯工具沿用 v0.2.0 的程式，仍需另行安裝、開啟並登入 XQ 個人版，以及可互動的 Windows 桌面；Skill 沒有附獨立 XS compiler。更新時保留當地環境，勿複製其他機器的 `.venv`。

## 驗證與限制

42 項測試全部通過，涵蓋補充索引查找、來源證據、錯誤參數、官方 URL 身分、拒絕混入手冊內文，以及 ZIP 解壓後的使用。正式 ZIP 含 38 個檔案，另以 uv 實測獨立解壓位置的查找與 CLI 入口。完整結果見 [驗證紀錄](https://github.com/pypysuper-og/xq-xs-skill-community/blob/v0.3.0/docs/validation.md)。

本版新增 API 參考未在 XQ 編譯或執行。桌面橋接程式沒有修改，四類「成功 → 故意錯誤 → 修正重編」沿用先前 XQ 個人版 3.20.04 261006 的證據；全部只編譯，沒有執行策略、回測或送單。
