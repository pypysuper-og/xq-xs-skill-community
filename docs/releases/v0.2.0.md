# v0.2.0｜搭配 XQ 桌面編譯 XS，使用 uv 管理環境

這個版本讓 Agent 寫完 XS 後，透過隨附 CLI 匯入 XQ、核對來源及腳本類型、觸發編譯、讀取錯誤，再修正與重新編譯。CLI 也能直接從命令列使用。

## 必要環境

**必須另外安裝、開啟並登入 XQ 個人版，並使用可互動的 Windows 桌面。這個 Skill 沒有附獨立 XS compiler。** 操作期間需讓鍵盤滑鼠空閒；工具會切換至 XQ。實測版本為 XQ 個人版 **3.20.04 261006**，其他版本與無頭 CI 尚未驗證。

Python 工具目前只使用標準函式庫。隨附 `pyproject.toml`、`.python-version` 與 `uv.lock`，以 uv 固定 **Python 3.13.5**，讓各台電腦自行建立 `.venv`。虛擬環境本體不在 ZIP 中。

## 新增內容

- `doctor` 檢查執行中的 XQ；`compile` 支援指標、選股、警示與交易四種腳本。
- 每次建立唯一名稱的測試腳本，核對編輯器完整來源與類型後，只送出一次 F6；不覆寫原有腳本。
- 回傳成功／失敗、錯誤數、來源雜湊與證據位置。有本機文字診斷時唯讀擷取；缺少文字時保存可見錯誤表格圖片，供 Agent 讀圖修正。
- 整理官方 XS VS Code 擴充套件的固定版本高亮規則與限制，保留 MIT 授權。
- 納入指定官方程式語法分類頁的 11 篇文章索引與原創案例導讀。

## 使用方式

下載 `xq-xs-community-v0.2.0.zip` 及同頁的 `.sha256`，核對後解壓並保留完整 `xq-xs/`。在該資料夾執行：

```powershell
uv sync --locked
uv run --locked python scripts/xq_compile.py doctor --json
uv run --locked python scripts/xq_compile.py compile assets/examples/ma-indicator.xs --type indicator --work-dir ./compile-evidence --json
```

`--locked` 在設定與鎖檔不一致時停止。首次若缺少指定 Python，uv 可能需要下載；不要搬移其他電腦的 `.venv`。完整前提、結束碼與修正流程見 [桌面編譯指南](https://github.com/pypysuper-og/xq-xs-skill-community/blob/v0.2.0/xq-xs/references/desktop-compile.md)。

## 驗證與限制

38 項 Python 測試通過，另驗證 ZIP 解壓後的 uv 使用及鎖檔不一致的拒絕行為。四種腳本各完成「正確例通過、故意錯誤例失敗、依診斷修正後通過」的 XQ 實機流程，細節見 [編譯驗證紀錄](https://github.com/pypysuper-og/xq-xs-skill-community/blob/v0.2.0/docs/compilation-validation.md)。

**部分錯誤只有圖片，行號與欄位尚未結構化擷取，亦未保證取得所有錯誤列。** CLI 本身不呼叫模型修正程式。自訂函數不在此次 CLI 支援範圍，兩個函數範例尚未實機編譯。

本次只編譯，沒有執行策略、回測、啟用雷達或送單；編譯成功不代表策略或實盤已驗證。套件與工具為社群維護，與嘉實資訊／XQ 無隸屬或背書關係。
