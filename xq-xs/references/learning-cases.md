# 官方程式語法文章：寫作參考案例

用於把交易敘述拆成 XS 條件、尋找學習範例及辨識資料情境。本套件於 2026-11-09 整理 [程式語法分類頁](https://www.xq.com.tw/xstrader/category/程式語法/) 當時可見的 11 篇文章；文章刊於 2016–2022 年。隨附的是連結索引與重新撰寫的學習重點，沒有收錄文章全文或上游策略程式。

以下是寫作檢查案例，並非已由本套件逐支編譯的策略。具體函數簽章、資料支援與交易行為須回到現行 XSHelp；文章日期不能當成目前 API 的更新日期。

## 從自然語言轉成條件

[選股常用語的對應程式集（二）](https://www.xq.com.tw/xstrader/選股常用語的對應程式集二/)（2019-03-21）適合學習門檻、歷史比較與交叉事件的差別。寫作時先問條件是「目前位於上方」，還是「這根 K 棒剛上穿」；前者可能連續成立，後者包含前一期的關係。把語句拆成中間條件，確認歷史引用和輸出數值後再組合。

[MACD 柱體反轉](https://www.xq.com.tw/xstrader/答客問之macd柱體反轉的寫法/)（2019-03-29）提醒：柱體正負、增減和第一次轉折是不同條件。「負值但開始回升」需要比較前後柱體，不能只檢查正負號。先清楚定義要找狀態或事件，再查 MACD 的現行參數與輸出。

## 量價、時間與自訂函數

[常用的語法匯總](https://www.xq.com.tw/xstrader/常用的語法匯總/)（2021-07-07）提供量價、計數及函數重用的案例線索。遇到價格乘成交量時先確認張／股與金額單位；累計值先定義何時重置。文章提到的自訂函數應先找出來源、建立及編譯，不能把函數名稱當成環境一定內建。

[預估量演算法](https://www.xq.com.tw/xstrader/依成交量分佈情況而設計的預估量演算法/)（2019-07-19）可用來討論盤中累積量、時段分布與全日估計的差別。歷史驗證只能使用該時間已知的成交量；不得拿收盤量回填成盤中已知資訊。

## 欄位與跨頻率

[當沖語法支援的欄位說明](https://www.xq.com.tw/xstrader/當沖語法支援的欄位說明/)（2019-08-20）適合對照報價、資料欄位與五檔資訊。先分辨最新報價和歷史序列，再核對欄位單位、商品與腳本類型；目前報價不能充當歷史五檔資料。

[跨頻率技術指標與策略雷達](https://www.xq.com.tw/xstrader/如何使用跨頻率技術指標來建構策略雷達/)（2019-07-31）適合說明高頻率／低頻率序列如何對位。將週線指標用於日線策略，並不等於把日線長度乘五；未完成的當期資料、歷史引用與洗價時機都需個別確認。細節搭配 [資料與時間](data-and-time.md)。

## 從選股到警示，再到交易

[多方警示策略步驟](https://www.xq.com.tw/xstrader/走進網友的交易室1-使用xs打造多方策略的步驟/)（2022-10-24）與 [空方警示策略步驟](https://www.xq.com.tw/xstrader/走進網友的交易室2-使用xs打造空方警示策略的步驟/)（2022-10-21）可用來拆解股票池、觸發條件、出場條件及雷達設定。這幾層應分開描述；警示不等於自動委託。文章中的週期近似換算，也不能一般化為完全相等的跨頻率計算。

[XQ 交易語法專章](https://www.xq.com.tw/xstrader/xq交易語法專章/)（2021-03-17）適合建立「目標部位、成交部位與成交紀錄」的區別。`SetPosition` 以目標部位表達意圖；檢查策略時須另外看 `Filled` 及成交成本。這是歷史教學，委託替換、價格及洗價規則仍須核對現行文件，搭配 [交易參考](autotrade.md)。

[網格交易介紹](https://www.xq.com.tw/xstrader/網格交易介紹/)（2021-04-29）可用來討論價格間距、持倉變化及部位上限。範例策略名稱不證明獲利，也不省略成本、跳空、部分成交與資金限制的驗證。

[學習地圖](https://www.xq.com.tw/xstrader/xslearnmap/)（2016-03-03）提供主題導航；使用時按目前版本確認編輯器介面與功能位置。

## 離線找案例

```text
python scripts/lookup.py 跨頻率 --source articles --json
python scripts/lookup.py MACD --source articles
python scripts/lookup.py Filled --source all --kind article
```

`articles` 只查這次分類頁索引；`help` 仍保留既有的 22 篇語法運用文章。`all` 合併三種索引查找，不代表完整搜尋 XQ 網站。查到後開啟原文，引用對當前判斷有用的少量內容即可。
